# Compilatio 
This is a compilation of tiny games made just to practice GLFW 
with C. And start making tools for future C projects so fell free do download and play

## Requirements:
There will be and Itch.io compiled version but for now it must be compiled by hand
- Makefile
- GLFW 3.14.x
- Glad with GL 3.0
- a console that supports Bash (if you are on windows probably gitBash)
- Gcc compiler
